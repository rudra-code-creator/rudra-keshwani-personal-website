# Personal website — Rudra Keshwani

Source for my personal site: portfolio, TIBER framework, experience, and contact.

**Live site:** [https://rudra-keshwani-personal-website.vercel.app](https://rudra-keshwani-personal-website.vercel.app)

## Stack

- [Next.js](https://nextjs.org/) 15 (App Router)
- TypeScript
- Tailwind CSS
- UI direction documented in [`DESIGN.md`](./DESIGN.md) (Raycast-inspired marketing chrome)

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deployment

The repository is connected to [Vercel](https://vercel.com/); pushes to the default branch trigger production deploys. Set `NEXT_PUBLIC_SITE_URL` in the Vercel project if you use a custom domain (optional, for Open Graph URLs).
